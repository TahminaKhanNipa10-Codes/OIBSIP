## 🚀 Task 1: Landing Page

### **LuxDrive — Premium Car Dealer Landing Page**

A visually stunning, fully responsive landing page for a luxury car dealership. This page is built with pure HTML and CSS, featuring an auto-sliding image carousel, smooth scrolling, and elegant dark theme.

### ✨ Features

- ✅ **Sticky Navigation Bar** with smooth scroll to sections
- ✅ **Hero Section** with tagline, headline, and call-to-action buttons
- ✅ **Auto-Sliding Image Carousel** (4 luxury car images)
- ✅ **Live Stats** (Happy Clients, Rating, Satisfaction)
- ✅ **Features Section** (Certified Pre-Owned, Financing, Service, Warranty)
- ✅ **Signature Collection** (3 car cards with specs)
- ✅ **Testimonials Section** (Client reviews)
- ✅ **Call-to-Action Banner** (Book a Test Drive)
- ✅ **Footer** with social links and newsletter subscription
- ✅ **Fully Responsive** (Desktop, Tablet, Mobile)
- ✅ **Pure HTML + CSS** (No JavaScript used)
- ✅ **Dark Elegant Theme** (Gold accents on navy background)

### 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Structure of the page |
| **CSS3** | Styling, layout, animations |
| **Flexbox** | Layout alignment |
| **CSS Grid** | Card layouts |
| **CSS Animations** | Auto-sliding carousel, hover effects |
| **Google Fonts** | Playfair Display + Inter fonts |
| **Font Awesome** | Icons |
